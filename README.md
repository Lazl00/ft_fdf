## Description

FdF (Fil de Fer) is a project that consists of creating a simplified 3D graphic representation of a relief landscape from a map file.

## Installation

```bash
git clone <repository-url>
cd fdf
make
```

## Usage

```bash
./fdf <map.fdf>
```

Example:

```bash
./fdf maps/42.fdf
```

## Controls

- `W` / `A` / `S` / `D` — Move the map
- `+` / `-` — Zoom
- Arrow keys — Rotate the map
- `ESC` — Exit
